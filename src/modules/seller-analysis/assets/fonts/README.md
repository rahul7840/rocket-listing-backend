# Fonts

`inter-400.ttf`, `inter-500.ttf`, `inter-600.ttf`, `inter-700.ttf` are the Inter typeface (Regular, Medium, SemiBold, Bold),
copyright The Inter Project Authors (https://github.com/rsms/inter), licensed under the SIL Open Font License 1.1
(https://openfontlicense.org). They are fetched from Google Fonts and used only to draw the seller analysis PDF
(Inter carries the rupee sign, which PDFKit's built-in fonts do not).
